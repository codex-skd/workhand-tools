# Workhand Tools

Workhand Tools is a Minecraft 26.2 (NeoForge) mod.

Adds a shovel and a pickaxe craftable from every vanilla material tier (wood, stone, iron, gold, diamond, netherite). Each tool matches the durability, mining speed and enchantability of its vanilla equivalent, and accepts the same enchantments as the base-game shovel/pickaxe.

## Status

Currently in early development (`0.0.0-beta.1`). Not yet feature complete.

## Requirements

| Component | Version |
|---|---|
| Minecraft | 26.2 |
| NeoForge | 26.2.0.32-beta |
| Java | 25+ |

## Installation

1. Install [NeoForge](https://neoforge.net/) for Minecraft 26.2.
2. Download the mod jar and place it in your `mods/` folder.
