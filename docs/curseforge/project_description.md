<h1 align="center">&#9968; Workhand Tools</h1>

<p align="center"><strong>A NeoForge tools mod for Minecraft 26.2. A pickaxe and a shovel, craftable in every vanilla material tier, with the exact durability, mining speed and enchantability of their base-game counterparts.</strong></p>

<br>

---

<br>

<h2>&#10024; Overview</h2>

<table>
<tr>
<td width="65%">
<p>Workhand Tools adds a second, purely cosmetic line of pickaxes and shovels — one per vanilla material tier (wood, stone, iron, gold, diamond, netherite) — with identical stats to their vanilla equivalents. No new mechanics, no rebalancing: same durability, same mining speed, same enchantability, same repair material, same enchantments.</p>

<p>Currently in early development (<code>0.0.0-beta.1</code>). No gameplay features are implemented yet — this description will be expanded as the tools are built.</p>
