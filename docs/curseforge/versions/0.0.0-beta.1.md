<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of Workhand Tools for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). Same tool line as the 26.2 build.</p>

<h3>About this build</h3>
<ul>
<li><strong>API port</strong> of the 26.2 source (41 classes, no mixins) to the 1.21.1 API.</li>
<li><strong>Tool materials</strong>: 26.2's <code>ToolMaterial</code> record &rarr; <code>SimpleTier</code>; the <code>Item.Properties.pickaxe()/axe()/hoe()/shovel()</code> builders don't exist in 1.21.1, so every tool item now extends its vanilla class (<code>PickaxeItem</code>/<code>AxeItem</code>/<code>HoeItem</code>/<code>ShovelItem</code>) with attributes from <code>createAttributes(tier, dmg, spd)</code>. Durability, mining speed, attack stats and enchantability are unchanged.</li>
<li><strong>Client rendering</strong> reverted from the 26.2 render-graph: <code>SubmitCustomGeometryEvent</code> &rarr; <code>RenderLevelStageEvent</code> + <code>LevelRenderer.renderLineBox</code> for the area highlight, chunk-border corners and tape-measure wireframe; <code>net.minecraft.gizmos</code> removed; in-world text via <code>Font.drawInBatch</code>; the Anchor Tome renderer collapsed to the classic block-entity-renderer form.</li>
<li><strong>Recipes</strong>: crafting ingredients wrapped to the 1.21.1 object form (<code>{"item":…}</code> / <code>{"tag":…}</code>).</li>
<li><strong>Full feature set</strong>: 12 pickaxes + 12 shovels (3 materials &times; 4 grades) with 3&times;3&rarr;5&times;5 area mining and the Cubic/Flat toggle, 4 improved vein-mining pickaxes, 2 tree-felling axes, 2 crop-harvesting hoes, Kennestroyer Pickaxe/Shovel (5 modes), Reinforced Deepslate Pickaxe, Tape Measure, and the Chunk Anchor + Anchor Tome forced-chunk-loading pair. Guide book via Vellumli.</li>
</ul>

<h3>Requirements</h3>
<ul>
<li>Minecraft 1.21.1 / NeoForge 21.1.249+</li>
<li><strong>Vellumli</strong> (required &mdash; in-game guide book)</li>
</ul>
