<h1>Workhand Tools 1.5.0</h1>

<h2>&#127912; All Item Textures Revamped</h2>
<p>Every workhand tool received a <strong>full texture refresh</strong>. All 24 tool textures (3 materials &times; 4 grades &times; pickaxe + shovel) now feature new artwork with improved detail, shading and material definition.</p>

<hr>

<h3>&#128273; What Changed</h3>
<ul>
<li><strong>24 new item textures</strong> replacing the previous art across all stone, iron and diamond tiers</li>
<li><strong>Visual grade progression</strong>: each grade tier (Basic, Advanced, Expert, Professional) is now more clearly distinguished</li>
<li><strong>Material identity</strong>: stone, iron and diamond tools now read clearly at a glance in inventory and hotbar</li>
</ul>

<h3>Unchanged</h3>
<ul>
<li>All gameplay systems remain identical to 1.4.0 &mdash; no balance or mechanic changes</li>
<li>Area mining, adaptive direction and mode toggles work exactly as before</li>
<li>Crafting recipes, durability, speed, enchantability and combat stats unchanged</li>
</ul>
