<h2>v0.0.0-beta.10 - Material scope reduction & local texture assets</h2>

<p>Major refactor: reduced from 10 materials (80 tools) to 3 core materials (Stone, Iron, Diamond = 24 tools). Each tool now has its own dedicated PNG texture file placeholder, ready for custom art replacement without code changes.</p>

<h3>Changes</h3>
<ul>
<li><strong>Scope reduction: 80 → 24 items</strong>
  <ul>
  <li>Removed materials: Wooden, Copper, Deepslate, Blackstone, Gold, Obsidian, Netherite</li>
  <li>Kept materials: Stone, Iron, Diamond (all 4 grades each × 2 tool types)</li>
  <li>Removed 56 items, keeping 24 tools + 1 robust_stick = 25 items total</li>
  </ul>
</li>
<li><strong>Local texture asset files created (25 PNG files)</strong>
  <ul>
  <li>Each item has dedicated PNG in <code>src/main/resources/assets/workhand_tools/textures/item/</code></li>
  <li>Filenames follow exact pattern: <code>{material}_workhand[_{grade}]_{tool_type}.png</code></li>
  <li>Example: <code>stone_workhand_pickaxe.png</code>, <code>iron_workhand_advanced_shovel.png</code>, <code>diamond_workhand_expert_pickaxe.png</code></li>
  <li>Placeholder PNGs are 16×16 px with material-specific colors</li>
  <li>Designer can replace PNGs directly — no model JSON or code changes needed</li>
  </ul>
</li>
<li><strong>Java code refactored</strong>
  <ul>
  <li><code>ModItems.java</code>: MATERIALS list reduced from 10 to 3 entries</li>
  <li><code>ModToolMaterials.java</code>: Cleaned up (no custom materials needed for Stone/Iron/Diamond)</li>
  <li>GRADES list unchanged (4 grades per material remain)</li>
  </ul>
</li>
<li><strong>JSON assets updated</strong>
  <ul>
  <li>25 item model JSONs (all 24 tools + robust_stick) now reference local textures (<code>workhand_tools:item/...</code>)</li>
  <li>Eliminated 56 model JSON files (removed materials)</li>
  <li>Eliminated 56 recipe JSON files (no crafting recipes for removed materials)</li>
  <li>Updated all tags: pickaxes.json, shovels.json, enchantable/* (durability, mining, mining_loot, vanishing)</li>
  </ul>
</li>
<li><strong>Localization updated</strong>
  <ul>
  <li><code>lang/en_us.json</code>: 24 tool names + robust_stick (removed 56 translations)</li>
  </ul>
</li>
<li><strong>Documentation updated</strong>
  <ul>
  <li><code>DESIGN_WORKHAND_TOOLS.md</code>: Updated concept section (80 → 24 items), materials table (10 → 3), implementation notes</li>
  <li><code>ASSET_LIST_WORKHAND_TOOLS.md</code>: 25 assets total (was 81)</li>
  <li><code>ASSET_PROMPTS_WORKHAND_TOOLS.md</code>: Switched from vanilla placeholder reference to local PNG file reference</li>
  </ul>
</li>
</ul>

<h3>What's Working</h3>
<ul>
<li>All 24 tools + robust_stick register, craft, and function correctly</li>
<li>Area-mining mechanics (AoE) remain fully functional for all 3 materials and 4 grades</li>
<li>Enchantments, durability, speed, and repair tags work as designed</li>
<li>Creative inventory displays 24 items in correct order (Stone/Iron/Diamond × grades 1-4, pickaxes then shovels)</li>
<li>Item icons render using placeholder PNG textures</li>
</ul>
