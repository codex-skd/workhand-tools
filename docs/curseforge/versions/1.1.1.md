<h1>Workhand Tools 1.1.1</h1>

<h2>&#128736; Hotfix</h2>

<p>Fixes a crash on startup caused by the experimental area preview highlight feature introduced in v1.1.0.</p>

<p>In NeoForge 26.2, <code>RenderLevelStageEvent</code> is an abstract class with concrete subclasses (<code>AfterSky</code>, <code>AfterOpaqueBlocks</code>, <code>AfterTranslucentBlocks</code>, etc.), and the gizmos system used for area highlighting is inaccessible during render-level events. The feature will be reimplemented using the correct <code>SubmitCustomGeometryEvent</code> API in a future update.</p>

<p><strong>All other v1.1.0 features remain intact:</strong> 10 language translations, descriptive tooltips, and the restored AoE mining system.</p>
