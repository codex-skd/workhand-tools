<h2>v1.10.2 - Fix: server crash from leaf decay</h2>

<h3>Fix</h3>
<ul>
<li><strong>Server crash (ConcurrentModificationException) in leaf decay</strong>: when a scheduled leaf decayed during the tick loop, it could synchronously trigger a neighbor-notify event that mutated the same internal tracking map being iterated at that moment, crashing the server. Leaves that are ready to decay are now collected first and ticked in a separate pass afterwards.</li>
</ul>
