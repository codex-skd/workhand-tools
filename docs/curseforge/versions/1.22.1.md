<h2>v1.22.1 - Kennestroyer Recipes Fixed</h2>

<blockquote><strong>The Kennestroyer Pickaxe and Shovel were uncraftable in v1.22.0 and earlier.</strong> Please update to this version.</blockquote>

<h3>Fix</h3>
<ul>
<li><strong>Kennestroyer recipes failed to load</strong>: both recipes used a shaped pattern with spaces between key letters for readability, but Minecraft counts every character (including spaces) as one grid column, so the pattern was rejected as too wide for a 3x3 crafting grid. Fixed — the Kennestroyer Pickaxe and Shovel are craftable again, with the same 3x3 layout as originally designed.</li>
</ul>
