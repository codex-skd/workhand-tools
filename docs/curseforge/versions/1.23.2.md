<h2>v1.23.2 - Workhand Hoes Enchantable</h2>

<h3>Fix</h3>
<ul>
<li><strong>Workhand Hoes could not be enchanted</strong>: the two hoes (iron/diamond) were the last tools still missing from the enchantment item tags, so the enchanting table offered nothing for them. They are now listed in a new <code>#minecraft:hoes</code> tag and in the four <code>#minecraft:enchantable/*</code> tags (mining, mining_loot, durability, vanishing). Every tool in the mod &mdash; pickaxes, shovels, axes, hoes, vein pickaxes, Kennestroyer Pickaxe/Shovel and the Reinforced Deepslate Pickaxe &mdash; now accepts standard enchantments just like its vanilla counterpart.</li>
</ul>
