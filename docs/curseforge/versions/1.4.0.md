<h1>Workhand Tools 1.4.0</h1>

<h2>&#127919; Face-Based Mining Direction</h2>

<p>Mining direction is now derived from the <strong>face of the block you're aiming at</strong> instead of the camera pitch angle. No more guesswork at steep angles &mdash; the tool always digs into the surface you're looking at.</p>

<table>
<tr><th>What you aim at</th><th>Mining direction</th></tr>
<tr><td><strong>Side face</strong> (wall)</td><td>Digs forward into the wall, toward where you look</td></tr>
<tr><td><strong>Top face</strong> (floor)</td><td>Digs downward</td></tr>
<tr><td><strong>Bottom face</strong> (ceiling)</td><td>Digs upward</td></tr>
</table>

<p>Applies equally to <strong>pickaxes and shovels</strong> at every grade. The area preview highlight uses the exact same logic, so what you see is always what gets mined.</p>

<hr>

<h2>Grades &amp; Area Mining</h2>
<table>
<tr><th>Grade</th><th>Pattern</th><th>Mode Toggle</th></tr>
<tr><td>Basic</td><td>3&times;3&times;1</td><td>&mdash;</td></tr>
<tr><td>Advanced</td><td>3&times;3&times;3 (Cubic) / 3&times;3&times;1 (Flat)</td><td>Right-click</td></tr>
<tr><td>Expert</td><td>5&times;5&times;1</td><td>&mdash;</td></tr>
<tr><td>Professional</td><td>5&times;5&times;5 (Cubic) / 5&times;5&times;1 (Flat)</td><td>Right-click</td></tr>
</table>

<h3>Controls</h3>
<ul>
<li><strong>Left-click</strong>: Break block + area (no sneaking)</li>
<li><strong>Shift + Left-click</strong>: Break single block (vanilla)</li>
<li><strong>Right-click</strong> (Grades 2 &amp; 4): Toggle Cubic / Flat mode</li>
</ul>
