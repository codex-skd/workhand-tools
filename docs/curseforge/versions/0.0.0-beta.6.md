<h2>v0.0.0-beta.6 - Fix duplicated drops on multi-part blocks</h2>

<p>Area mining, vein mining and tree felling no longer duplicate the drops of blocks that occupy more than one block space.</p>

<h3>Fixed</h3>
<ul>
<li><strong>AoE mining, vein mining and tree felling duplicated the drops of multi-part or special blocks.</strong> Breaking a block such as a Waystones waystone, a bed, a tall flower or this mod's own Chunk Anchor as an <em>extra</em> block of an area / vein / felling pass dropped its item twice &mdash; roughly once per sub-block it occupies. The internal break helper hand-rolled the break as <code>playerWillDestroy</code> + <code>Block.dropResources</code> + <code>setBlock</code>, but many of these blocks already drop their item from inside <code>playerWillDestroy</code>, so <code>Block.dropResources</code> was an extra drop on top. It now mirrors the vanilla player-break sequence (<code>playerWillDestroy</code> &rarr; <code>onDestroyedByPlayer</code> &rarr; <code>Block.destroy</code> &rarr; <code>Block.playerDestroy</code>), so every block drops exactly once, just like breaking it by hand. The block you directly target was never affected &mdash; only the extra blocks broken by the tool's area/vein/felling pass.</li>
</ul>

<h3>Requirements</h3>
<ul>
<li>Minecraft 1.21.1 / NeoForge 21.1.249+</li>
<li><strong>Vellumli</strong> (required &mdash; in-game guide book)</li>
</ul>
