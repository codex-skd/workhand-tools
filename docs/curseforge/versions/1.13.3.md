<h1>Workhand Tools 1.13.3</h1>

<h2>&#9935; AoE Outline Now Matches What Actually Breaks</h2>
<p>The area-mining outline could keep highlighting a block that the tool couldn't actually mine, making the preview disagree with the real result.</p>

<hr>

<h3>Fix</h3>
<p>The outline only checked whether the tool was correct for the targeted block once, then drew every non-air block in the pattern regardless of whether the tool could mine it. The actual mining logic already checked this per block. The outline now applies the same per-block check, so it always shows exactly the blocks that will actually break.</p>
