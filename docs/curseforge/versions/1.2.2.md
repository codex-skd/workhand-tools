<h1>Workhand Tools 1.2.2</h1>

<h2>&#128736; Crash Fix</h2>
<p>Fixed <code>Missing elements in vertex</code> crash in the area highlight renderer. The previous implementation used manual <code>VertexConsumer</code> calls which lacked required UV coordinates for the <code>LINES_TRANSLUCENT</code> render type. Switched to <code>submitShapeOutline</code> which handles vertex formats correctly.</p>
