<h2>v1.2.0 - Advancements (Minecraft 1.21.1)</h2>

<p>Adds a dedicated <strong>Workhand Tools advancement tab</strong> with nine milestone
advancements, each unlocked the moment you <strong>craft</strong> the matching tool.</p>

<h3>Added</h3>
<ul>
<li><strong>Workhand Tools</strong> &mdash; craft a Robust Stick to open the tab.</li>
<li><strong>Getting to Work</strong> &mdash; craft your first Workhand pickaxe or shovel.</li>
<li><strong>Bigger Is Better</strong> &mdash; craft a Professional-grade Workhand pickaxe or shovel.</li>
<li><strong>Follow the Vein</strong> &mdash; craft an Improved vein-mining pickaxe.</li>
<li><strong>Timber!</strong> &mdash; craft a Workhand Axe.</li>
<li><strong>Reap What You Sow</strong> &mdash; craft a Workhand Hoe.</li>
<li><strong>The Kennestroyer</strong> <em>(challenge)</em> &mdash; craft a Kennestroyer ultimate tool.</li>
<li><strong>Overbuilt</strong> &mdash; craft the Reinforced Deepslate Pickaxe.</li>
<li><strong>Stay Loaded</strong> &mdash; craft a Chunk Anchor.</li>
</ul>

<h3>Notes</h3>
<blockquote>Data-only addition (nine advancement JSON files + English/Spanish strings; other
languages fall back to English). Triggered by <code>minecraft:recipe_crafted</code>, so each
advancement pops on the craft itself. Verified: <code>./gradlew runServer</code> reaches
<code>Done</code> and loads the datapack with 0 parse errors. No changes to tools, recipes,
config or keybindings. Shares this CurseForge project with the 26.2 line &mdash; pick the file
that matches your Minecraft version. Requires Vellumli for the in-game guide book.</blockquote>
