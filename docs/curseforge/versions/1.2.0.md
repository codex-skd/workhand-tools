<h1>Workhand Tools 1.2.0</h1>

<h2>&#127754; Adaptive Mining Direction</h2>

<p>The area mining pattern now <strong>adapts to where you're looking</strong>. No more awkward mining when digging floors or ceilings!</p>

<table>
<tr><th>Where you look</th><th>Pattern behavior</th><th>Example</th></tr>
<tr><td><strong>Horizontal</strong> (wall)</td><td>Extends <em>forward</em> from aimed block into the wall</td><td>Mining a tunnel face</td></tr>
<tr><td><strong>Down</strong> (pitch &gt; 60&deg;)</td><td>Centered square, extends <em>downward</em></td><td>Digging a pit</td></tr>
<tr><td><strong>Up</strong> (pitch &lt; -60&deg;)</td><td>Centered square, extends <em>upward</em></td><td>Clearing a ceiling</td></tr>
</table>

<p>Lateral width is always centered on the aimed block regardless of direction.</p>

<hr>

<h2>Grades &amp; Area Mining</h2>
<table>
<tr><th>Grade</th><th>Pattern</th><th>Mode Toggle</th></tr>
<tr><td>Basic</td><td>3&times;3&times;1</td><td>&mdash;</td></tr>
<tr><td>Advanced</td><td>3&times;3&times;3 (Cubic) / 3&times;3&times;1 (Flat)</td><td>Right-click</td></tr>
<tr><td>Expert</td><td>5&times;5&times;1</td><td>&mdash;</td></tr>
<tr><td>Professional</td><td>5&times;5&times;5 (Cubic) / 5&times;5&times;1 (Flat)</td><td>Right-click</td></tr>
</table>

<h3>Controls</h3>
<ul>
<li><strong>Left-click</strong>: Break block + area (no sneaking)</li>
<li><strong>Shift + Left-click</strong>: Break single block (vanilla)</li>
<li><strong>Right-click</strong> (Grades 2 &amp; 4): Toggle Cubic / Flat mode</li>
</ul>
