<h1>Workhand Tools 1.6.1</h1>

<h2>&#129686; New Tools: Axes &amp; Vein-Mining Pickaxes</h2>
<p>Two new tool families join the Workhand lineup, plus a mining-direction fix that makes Cubic mode dig the full volume it always should have.</p>

<hr>

<h3>&#129687; Workhand Axes</h3>
<p>Iron and Diamond axes with toggleable <strong>tree felling</strong>. Right-click to enable, then break any log and the whole connected tree comes down with it.</p>

<h3>&#9935;&#65039; Vein-Mining Improved Pickaxes</h3>
<p>Advanced and Professional improved pickaxes (Iron/Diamond) that chain-break connected ore blocks of the same type, on top of their normal area mining.</p>

<h3>&#127912; Final Artwork Applied</h3>
<p>Placeholder textures for all 24 tools, the 4 improved pickaxes and the 2 axes have been replaced with the designer's final art.</p>

<hr>

<h2>&#128295; Fixes</h2>
<ul>
<li><strong>Cubic mode now mines the full volume</strong>: area mining in Cubic mode only ever broke a single <code>NxNx1</code> layer instead of the full <code>NxNxN</code> cube, and aiming a few degrees off the block's face could flip the whole pattern sideways. Digging direction is now derived from a real raytrace along the player's view instead of an approximation based on where the player is standing, so the tool always digs forward into the aimed surface.</li>
<li><strong>Duplicate tooltip line removed</strong> on improved pickaxes ("Hold Shift for normal mining" was showing twice).</li>
<li><strong>Broken tooltip color codes fixed</strong> across all 10 languages &mdash; some control-hint lines were rendering with the wrong color or as literal escape text instead of gray.</li>
</ul>
