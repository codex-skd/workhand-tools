<h2>v0.0.0-beta.4 - Critical fix: crash on startup (ExceptionInInitializerError)</h2>

<p><strong>0.0.0-beta.3 loaded but crashed during startup</strong> with <code>ExceptionInInitializerError</code> while dispatching <code>FMLCommonSetupEvent</code>, confirmed against a real crash report.</p>

<h3>Fixed</h3>
<ul>
<li>Java static field initialization order bug in the internal item registry: the fields listing all 80 tools were declared before the fields they depend on (the material list, the grade list, and the id lookup map), so those dependencies were still <code>null</code> the moment the tool list tried to use them. Reordered the fields so dependencies are declared first.</li>
</ul>

<blockquote>If 0.0.0-beta.3 crashed for you right after the main menu / world load with an ExceptionInInitializerError mentioning Workhand Tools, update to this version.</blockquote>
