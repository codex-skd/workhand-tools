<h2>v0.0.0-beta.4 - Rebindable Hoe mode key</h2>

<p>The Workhand Hoe's Till/Harvest mode toggle no longer depends on canceling the vanilla right-click interaction. It now uses a dedicated, rebindable keybinding, defaulted to the right mouse button so nothing changes for you out of the box.</p>

<h3>Changed</h3>
<ul>
<li><strong>Hoe mode toggle moved to a keybinding</strong> (<code>Options &gt; Controls &gt; Workhand Tools</code>), bound to the right mouse button by default. Previously the toggle raced against the vanilla hoe's own right-click tilling behavior, so it sometimes didn't fire. Right-click still blocks the vanilla "till dirt" interaction while holding a hoe; the mode itself is now switched only through the keybinding, which you're free to rebind to any key.</li>
</ul>

<h3>Requirements</h3>
<ul>
<li>Minecraft 1.21.1 / NeoForge 21.1.249+</li>
<li><strong>Vellumli</strong> (required &mdash; in-game guide book)</li>
</ul>
