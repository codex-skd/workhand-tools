<h1>Workhand Tools 1.7.0</h1>

<h2>&#128207; New Tool: Tape Measure</h2>
<p>Measure the exact area between any two blocks &mdash; handy for planning builds, farms, and bases.</p>

<hr>

<h3>How it works</h3>
<ul>
<li><strong>Right-click</strong> a block to set the start point.</li>
<li><strong>Right-click again</strong> on another block to set the end point &mdash; a wireframe box appears with the X/Y/Z side lengths labeled.</li>
<li><strong>Shift + right-click</strong> undoes the last measurement.</li>
<li>Before confirming, the pending box follows your crosshair in real time so you can preview the measurement as you look around.</li>
</ul>

<h3>Configurable</h3>
<p>Line color, text color, text size and line width can all be tuned from the mod's config screen (client-side).</p>
