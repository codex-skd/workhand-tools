<h2>v1.14.0 - Workhand Hoes: Crop Right-Click Harvesting</h2>

<h3>Feature</h3>
<ul>
<li><strong>Two new tools</strong>: <code>Iron Workhand Hoe</code> and <code>Diamond Workhand Hoe</code>, built on the same Improved Iron/Diamond materials as the Workhand Axes (high durability, vanilla speed/enchantability).</li>
<li><strong>Right-click to harvest</strong>: right-clicking a mature crop, cocoa, or nether wart block harvests it and instantly replants it in place — no seeds required in your inventory, and drops respect Fortune and other mining enchantments on the hoe.</li>
<li><strong>Area harvesting by tier</strong>: harvesting spreads to every other mature crop on the same level around the targeted block — a 3&times;3 area for the Iron Workhand Hoe, 5&times;5 for the Diamond Workhand Hoe.</li>
<li><strong>Durability cost</strong>: each block harvested consumes 1 durability point from the hoe, same as normal tool use.</li>
</ul>

<h3>Notes</h3>
<ul>
<li>Scope is limited to crops that grow "in place" by aging (wheat, carrots, potatoes, beetroot, any modded crop extending the vanilla crop block, cocoa, and nether wart). Plants that grow by stacking multiple blocks (sugar cane, cactus, bamboo) are not affected.</li>
<li>Item textures are placeholder vanilla hoe textures for now, consistent with the rest of the mod's current asset status.</li>
</ul>
