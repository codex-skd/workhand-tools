# Workhand Tools 0.0.0-beta.5

**Critical Fix:** Resolved mod loading crash caused by premature static initialization of ModItems.

## What's Fixed

- **Mod Loading Crash**: Previous version crashed with `NullPointerException: Item id not set` during DeferredRegister phase. Root cause was a static initializer block in `WorkhandTools.java` that tried to access `ModItems.PICKAXES` before the `DeferredRegister` was ready to register items, resulting in items being created without valid IDs.
- **Simplified Initialization**: Reverted unnecessary `Supplier<ToolMaterial>` changes and getter methods. The mod now uses straightforward initialization without premature eager loading.
- **Temporary Note**: Item grade lookups (`buildLookups()`) temporarily disabled while deeper static initializer issues are investigated. Core mod functionality (all 80 items, recipes, enchantments, and AoE mining mechanics) remain fully operational.

## Compatibility

- **Minecraft**: 26.2
- **NeoForge**: 26.2.0.32-beta
- No dependency changes from previous version.
