<h2>v0.0.0-beta.5 - Rebindable AoE/felling keys + connection fix</h2>

<p>Fixes a connection issue introduced in beta.4 and extends the rebindable mode-toggle keybinding to every Workhand tool that has one.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Could get disconnected joining a server on an older Workhand Tools version.</strong> The network channel added in beta.4 was required on both sides; a mismatch triggered NeoForge's mod-mismatch disconnect screen instead of just degrading gracefully. Now optional.</li>
<li><strong>AoE mining mode (pickaxes/shovels) and tree felling mode (axes) could stop responding to right-click</strong> in modpacks where another mod intercepts right-click on those tools first (e.g. a combat mod treating axes/pickaxes as weapons with their own right-click ability). Both now use a dedicated, rebindable keybinding (<code>Options &gt; Controls &gt; Workhand Tools</code>), defaulted to the right mouse button - same fix already shipped for the Hoe in beta.4.</li>
</ul>

<h3>Requirements</h3>
<ul>
<li>Minecraft 1.21.1 / NeoForge 21.1.249+</li>
<li><strong>Vellumli</strong> (required &mdash; in-game guide book)</li>
</ul>

<h3>Notes</h3>
<blockquote>Verified: <code>./gradlew clean build</code> OK. Not yet visually verified in a running client.</blockquote>
