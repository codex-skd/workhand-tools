<h2>&#129521; Area Mining</h2>
<table>
<tr><th>Grade</th><th>Pattern</th><th>Mode Toggle</th><th>Direction</th></tr>
<tr><td>Basic</td><td>3&times;3&times;1</td><td>&mdash;</td><td>Adaptive</td></tr>
<tr><td>Advanced</td><td>3&times;3&times;3 (Cubic) / 3&times;3&times;1 (Flat)</td><td>Right-click</td><td>Adaptive</td></tr>
<tr><td>Expert</td><td>5&times;5&times;1</td><td>&mdash;</td><td>Adaptive</td></tr>
<tr><td>Professional</td><td>5&times;5&times;5 (Cubic) / 5&times;5&times;1 (Flat)</td><td>Right-click</td><td>Adaptive</td></tr>
</table>

<h3>Adaptive Direction</h3>
<ul>
<li><strong>Horizontal</strong> (wall): pattern extends forward into the wall</li>
<li><strong>Down</strong> (floor, pitch &gt; 50&deg;): centered square, extends downward</li>
<li><strong>Up</strong> (ceiling, pitch &lt; -50&deg;): centered square, extends upward</li>
</ul>

<h2>&#128064; Area Preview</h2>
<p>Soft white outlines highlight the blocks that will be affected. Only renders on solid blocks &mdash; no empty wireframes in air.</p>

<h2>&#127758; 10 Language Translations</h2>
<p>English, Spanish, Portuguese, French, German, Russian, Simplified Chinese, Japanese, Italian, Korean.</p>

<h3>Controls</h3>
<ul>
<li><strong>Left-click</strong>: Area mine (no sneaking)</li>
<li><strong>Shift + Left-click</strong>: Single block (vanilla)</li>
<li><strong>Right-click</strong> (Grades 2 &amp; 4): Toggle Cubic / Flat</li>
</ul>

<h3>Crafting</h3>
<p>Grade progression uses increasingly expensive materials (ingots &rarr; blocks &rarr; Robust Stick component for Expert/Professional). All recipes visible in JEI.</p>
