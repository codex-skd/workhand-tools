<h2>v1.3.0 - The Workhand Hoe is a pure mode tool (Minecraft 1.21.1)</h2>

<p>The <strong>Workhand Hoe no longer breaks blocks</strong>. Its primary (left) button is now
reserved entirely for the selected mode &mdash; <em>Till</em> or <em>Harvest &amp; Replant</em>,
switched with the secondary button / keybind &mdash; and nothing else.</p>

<h3>Changed</h3>
<ul>
<li><strong>No accidental mining.</strong> Left-clicking a block with a Workhand Hoe in survival
never starts breaking it (same mechanic vanilla uses for swords). Creative players can still
break blocks normally.</li>
<li><strong>Immature crops are safe.</strong> In Harvest mode, left-clicking a crop that is not
fully grown does nothing instead of destroying it &mdash; the plant is left to keep growing.
Mature crops still area-harvest and replant exactly as before.</li>
<li>Clicking a non-tillable block in Till mode is now a no-op instead of breaking it.</li>
</ul>

<h3>Notes</h3>
<blockquote>Behaviour change only &mdash; no changes to hoe stats, harvest radius, drops, sounds
or durability cost. Verified: <code>./gradlew clean build</code> is green. Shares this CurseForge
project with the 26.2 line &mdash; pick the file that matches your Minecraft version. Requires
Vellumli for the in-game guide book.</blockquote>
