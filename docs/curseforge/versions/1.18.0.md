<h2>v1.18.0 - Guide Book Fixes &amp; First-Join Gift</h2>

<h3>Feature</h3>
<ul>
<li><strong>Guide book given on first join</strong>: every player now receives the Workhand Tools guide book automatically the first time they log in (tracked per-player, survives death/respawn). If lost afterward, it has to be crafted again (book + iron ingot + diamond) — it's a one-time gift, not a repeatable freebie.</li>
</ul>

<h3>Fix</h3>
<ul>
<li><strong>Guide book missing from the creative tab / JEI</strong>: <code>book.json</code>'s <code>creative_tab</code> field was a bare <code>workhand_tab</code> string, which Vellumli parses as a namespaced Identifier and silently resolved to <code>minecraft:workhand_tab</code> (a tab that doesn't exist) — the book never made it into our own creative tab. Fixed to <code>workhand_tools:workhand_tab</code>.</li>
<li><strong>Book name/subtitle were too long for the tooltip</strong>: shortened <code>book.name</code> and <code>book.subtitle</code> to 2 words max across all 10 languages; the longer wording lives in <code>book.landing</code> instead.</li>
</ul>

<h3>Change</h3>
<ul>
<li>Updated the bundled Vellumli dependency to 1.2.0 — adds JEI search support for the guide book and drops Vellumli's bundled demo book.</li>
</ul>
