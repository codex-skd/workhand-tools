<h2>v0.0.0-beta.2 - Client crash fix</h2>

<p>Fixes a crash on world/client startup introduced by the 1.21.1 port. If <code>beta.1</code> loaded fine on your dedicated server but crashed the client, this is the build you want.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Client mod-loading crash</strong>: <code>class com.skd.workhandtools.WorkhandToolsClient has no @SubscribeEvent methods, but register was called anyway</code>. The client entry class carried an <code>@EventBusSubscriber</code> annotation but has no static <code>@SubscribeEvent</code> methods (its only listener is wired manually in the constructor). NeoForge's <code>AutomaticEventSubscriber</code> then tried to <code>bus.register()</code> the class and aborted mod loading. The annotation has been removed &mdash; the same fix that the main <code>WorkhandTools</code> class already uses. Dedicated-server loading never touched this class, so the bug only showed up on a real client.</li>
</ul>

<h3>Requirements</h3>
<ul>
<li>Minecraft 1.21.1 / NeoForge 21.1.249+</li>
<li><strong>Vellumli</strong> (required &mdash; in-game guide book)</li>
</ul>

<h3>Notes</h3>
<blockquote>Verified: <code>./gradlew clean build</code> OK. Client rendering (floating tome, area highlight, tape-measure wireframe) still not visually verified in a running client.</blockquote>
