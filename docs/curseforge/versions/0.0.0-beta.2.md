<h2>v0.0.0-beta.2 - First functional release</h2>

<p>First release with actual gameplay content. Workhand Tools now adds a pickaxe and a shovel for 10 materials, each in 4 grades that unlock area mining.</p>

<h3>Added</h3>
<ul>
<li><strong>80 tools</strong>: pickaxe and shovel for Wood, Stone, Copper, Deepslate, Iron, Blackstone, Gold, Diamond, Obsidian and Netherite, each in 4 grades (base, Advanced, Expert, Professional).</li>
<li><strong>Vanilla-matched stats</strong>: durability, mining speed, attack damage and enchantability are identical to their vanilla equivalents for Wood/Stone/Iron/Gold/Diamond/Netherite. Copper, Deepslate, Blackstone and Obsidian use custom tool materials balanced between the closest vanilla tiers.</li>
<li><strong>Area mining (AoE)</strong>: higher grades break blocks in a pattern around the targeted block — 3x3x1 (base grade), 3x3x3 or 3x3x1 (Advanced, toggle with right-click), 5x5x1 (Expert), 5x5x5 or 5x5x1 (Professional, toggle with right-click). Sneaking always breaks only the targeted block. The 5-tall patterns anchor differently depending on where you're looking, so mining a comfortable tunnel at eye level doesn't require crouching to see the floor.</li>
<li><strong>Recipes</strong>: each of the 4 grades has its own shaped recipe, using progressively more refined materials and a new <code>Robust Stick</code> item for the higher grades. Netherite tools upgrade from their Diamond equivalent via a smithing table, like vanilla.</li>
<li><strong>Enchantments</strong>: every tool accepts the same enchantments as vanilla pickaxes/shovels (Efficiency, Fortune, Silk Touch, Unbreaking, Mending, Curse of Vanishing).</li>
</ul>

<h3>Notes</h3>
<ul>
<li>All 80 tools currently use placeholder textures borrowed from the closest vanilla tool — custom artwork is commissioned and in progress.</li>
<li>Only English is supported for now; more languages are planned.</li>
</ul>

<blockquote>Still in early beta — balance and the area-mining feel may change based on testing.</blockquote>
