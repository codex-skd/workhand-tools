<h1>Workhand Tools 1.2.1</h1>

<h2>&#128064; Smoother Area Preview</h2>
<p>The block highlight now uses <code>SubmitCustomGeometryEvent</code> with translucent line rendering — the same technique used by CoKTools. This produces a clean soft white border around affected blocks that's consistent and flicker-free.</p>

<h2>&#128208; Better Vertical Detection</h2>
<p>Vertical mining threshold lowered from 60&deg; to 50&deg; for a more natural transition between horizontal and vertical modes.</p>

<hr>

<h3>Controls</h3>
<ul>
<li><strong>Left-click</strong>: Area mine (no sneaking)</li>
<li><strong>Shift + Left-click</strong>: Single block</li>
<li><strong>Right-click</strong> (Grades 2 &amp; 4): Toggle Cubic / Flat</li>
</ul>
