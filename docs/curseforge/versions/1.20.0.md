<h2>v1.20.0 - Vellumli Required + Full Recipe Integration</h2>

<h3>Feature</h3>
<ul>
<li><strong>Vellumli is now a required dependency</strong>: the mod will fail to load with a clear error message if Vellumli is not installed. This ensures the in-game guide book is always available.</li>
<li><strong>Complete recipe integration in the guide book</strong>: every tool and utility item now has its crafting recipe displayed directly in the Vellumli guide book using the native <code>vellumli:crafting</code> page type. No need for JEI to see recipes.</li>
</ul>

<h3>Content</h3>
<ul>
<li><strong>Pickaxes</strong>: 18 recipes (Stone/Iron/Diamond × all grades 1-4 + improved variants)</li>
<li><strong>Shovels</strong>: 12 recipes (Stone/Iron/Diamond × all grades 1-4)</li>
<li><strong>Axes</strong>: 2 recipes (Iron, Diamond)</li>
<li><strong>Hoes</strong>: 2 recipes (Iron, Diamond)</li>
<li><strong>Vein-Mining Pickaxes</strong>: 4 recipes (Improved Iron/Diamond Professional + Advanced)</li>
<li><strong>Utility Items</strong>: 5 recipes (Tape Measure, Robust Stick, Chunk Anchor, Anchor Tome, Guide Book)</li>
</ul>

<h3>Change</h3>
<ul>
<li>Vellumli dependency changed from optional to required in <code>neoforge.mods.toml</code></li>
<li>Startup validation added: mod throws <code>IllegalStateException</code> if Vellumli is missing</li>
</ul>

<h3>Translation</h3>
<ul>
<li>All new recipe pages added in both English (en_us) and Spanish (es_es)</li>
</ul>
