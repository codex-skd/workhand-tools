<h2>v1.23.1 - Kennestroyer Tools Enchantable</h2>

<h3>Fix</h3>
<ul>
<li><strong>Kennestroyer Pickaxe and Shovel still could not be enchanted</strong>: v1.23.0 announced that these two tools accepted enchantments like the rest of the mod, but their IDs were never added to the required item tags, so the enchanting table offered nothing for them. They are now listed in <code>#minecraft:pickaxes</code> / <code>#minecraft:shovels</code> and in the four <code>#minecraft:enchantable/*</code> tags (mining, mining_loot, durability, vanishing), just like every other tool. They now accept Efficiency, Fortune, Silk Touch, Unbreaking, Mending, Curse of Vanishing, and any other enchantment tied to the tool type.</li>
</ul>
