<h1>Workhand Tools 1.9.0</h1>

<h2>&#127811; Faster Leaf Decay</h2>
<p>Leaves left floating without wood support now disappear noticeably faster.</p>

<hr>

<h3>How it works</h3>
<p>Whenever a block next to leaves is removed &mdash; by hand, an axe, an explosion, anything &mdash; an early decay check is forced a few ticks later instead of waiting on vanilla's natural random-tick interval. No more waiting around for leftover leaves to slowly disappear after clearing a tree.</p>
<p>This is a global effect: it applies everywhere, not just when using a Workhand Axe.</p>
