<h2>v0.0.0-beta.12 - Item Model Definitions Fixed</h2>

<h3>Fix</h3>
<ul>
<li><strong>Issue</strong>: Item textures displayed as magenta placeholders in creative inventory and hand. Root cause: missing item model definition files in <code>assets/workhand_tools/items/</code>.</li>
<li><strong>Resolution</strong>: Added <code>items/*.json</code> definition files for all 25 items (12 pickaxes + 12 shovels + 1 stick), each referencing the corresponding model in <code>models/item/</code>.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Added <code>WorkhandPickaxeItem</code> — custom Item subclass using vanilla pickaxe property configuration.</li>
<li>Refactored <code>ModItems.java</code> — individual DeferredItem registrations for each tool, replacing generic loop-based approach.</li>
<li>Created 25 JSON files: <code>assets/workhand_tools/items/{item_name}.json</code> with model pointers to <code>workhand_tools:item/{item_name}</code>.</li>
</ul>

<h3>Developer Notes</h3>
<p>In NeoForge 26.2, items requiring model definitions (tools, pickaxes, shovels) need both:</p>
<ol>
<li>Model JSON: <code>assets/namespace/models/item/name.json</code> (visual geometry and parent)</li>
<li>Item definition: <code>assets/namespace/items/name.json</code> (data component linking to model)</li>
</ol>
<p>Omitting item definitions causes Minecraft to render the missing-texture magenta placeholder.</p>
