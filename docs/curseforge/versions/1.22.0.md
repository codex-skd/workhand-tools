<h2>v1.22.0 - Reinforced Deepslate Pickaxe</h2>

<h3>Feature</h3>
<ul>
<li><strong>Reinforced Deepslate Pickaxe</strong>: a standalone pickaxe with a single purpose — mining Reinforced Deepslate at very high speed (equivalent to how fast a Diamond Pickaxe breaks stone). It is otherwise a non-functional pickaxe: it cannot efficiently mine any other block. No area mining, no vein mining, always breaks one block at a time. Accepts the full standard pickaxe enchantment set (Efficiency, Fortune, Silk Touch, Unbreaking, Mending, Curse of Vanishing). Crafted from 7 Netherite Ingots, a Diamond Workhand Professional Improved Pickaxe, and a Reinforced Deepslate block.</li>
<li><strong>Reinforced Deepslate loot table override</strong>: in vanilla Minecraft, Reinforced Deepslate drops nothing when broken, with any tool, even Silk Touch. This mod adds a loot table override so Reinforced Deepslate drops itself when broken specifically with a Diamond Workhand Professional Improved Pickaxe, enabling the crafting chain for the new pickaxe above.</li>
</ul>

<h3>Fix</h3>
<ul>
<li><strong>Kennestroyer mode cycle looked incomplete</strong>: a freshly crafted Kennestroyer Pickaxe/Shovel defaulted to a leftover state that made the first right-click appear to skip a mode, and the mode message only said generic "Cubic"/"Flat" without showing the area size. Now defaults to Disabled and shows the exact area (Disabled, 3x3x1, 3x3x3, 5x5x1, 5x5x5) on every right-click and in the tooltip.</li>
</ul>
