<h1>Workhand Tools 1.13.2</h1>

<h2>&#9935; Chunk Anchor Now Actually Breakable</h2>
<p>Quick follow-up to 1.13.0/1.13.1: the Chunk Anchor pedestal took its full uncut destroy time to mine with any pickaxe, including diamond and netherite.</p>

<hr>

<h3>Fix</h3>
<p>The block copied Obsidian's full properties for its 50-second base toughness, but was never added to the pickaxe tag &mdash; so no pickaxe got its mining-speed bonus applied, making it take the whole 50 seconds to break by hand. It now mines at the expected speed with any pickaxe while keeping Obsidian's original toughness.</p>
