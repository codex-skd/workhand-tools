<h2>v0.0.0-beta.3 - Chunk Anchor texture fix</h2>

<p>Fixes the <strong>Chunk Anchor</strong> showing up as the black/magenta missing-texture placeholder in the inventory, in hand and on the ground. Introduced by the 1.21.1 port; the block itself and every other item were unaffected.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Chunk Anchor rendered as the missing-texture placeholder</strong>. <code>chunk_anchor</code> was the only registered item without a <code>assets/workhand_tools/models/item/chunk_anchor.json</code>. On Minecraft 1.21.1 a <code>BlockItem</code>'s inventory model is resolved from <code>models/item/&lt;name&gt;.json</code>; the <code>assets/workhand_tools/items/</code> folder (the 1.21.4+ <em>item model definition</em> format, carried over from the 26.2 source) does nothing on this version, so the item fell back to the missing model. Added the missing model, parented to <code>workhand_tools:block/chunk_anchor</code> so the item reuses the block's Blockbench model and <code>gui</code> display transform &mdash; the same way every other block item works in vanilla. The texture file itself was always present and correct.</li>
</ul>

<h3>Requirements</h3>
<ul>
<li>Minecraft 1.21.1 / NeoForge 21.1.249+</li>
<li><strong>Vellumli</strong> (required &mdash; in-game guide book)</li>
</ul>
