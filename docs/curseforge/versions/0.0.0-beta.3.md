<h2>v0.0.0-beta.3 - Critical fix: the mod wasn't loading</h2>

<p><strong>0.0.0-beta.2 did not work at all.</strong> A build configuration bug meant the jar never included a valid <code>META-INF/neoforge.mods.toml</code>, so NeoForge silently skipped the mod on startup ("not a valid mod file"). This release fixes it — the mod actually loads now.</p>

<h3>Fixed</h3>
<ul>
<li>Corrected the <code>generateModMetadata</code> Gradle task path so the mod manifest template is found and its placeholders (mod id, version, display name, license) are properly resolved into the final jar.</li>
</ul>

<blockquote>If you tried 0.0.0-beta.2 and the mod didn't show up in your mods list, that's why — update to this version.</blockquote>
