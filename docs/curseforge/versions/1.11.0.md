<h1>Workhand Tools 1.11.0</h1>

<h2>&#9935; Turn Off Area Mining, Anytime</h2>
<p>Right-click on any Workhand pickaxe now lets you fully disable area mining, not just switch between Cubic and Flat.</p>

<hr>

<h3>How it works</h3>
<p>Every pickaxe grade now cycles through an extra &quot;Disabled&quot; state when you right-click:</p>
<ul>
<li><strong>Grade 1 &amp; Grade 3</strong> (flat-only area): <code>Disabled &rarr; Flat &rarr; Disabled</code></li>
<li><strong>Grade 2 &amp; Grade 4</strong> (Cubic/Flat capable): <code>Disabled &rarr; Flat &rarr; Cubic &rarr; Disabled</code></li>
</ul>
<p>Existing pickaxes keep mining in area mode by default, exactly like before &mdash; nothing changes unless you right-click. The tooltip always shows the current state and reminds you that right-click switches it.</p>
