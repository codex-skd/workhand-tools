<h2>v0.0.0-beta.7 - Spanish locale completion</h2>

<p>Translation-only beta for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>. No code changes.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Spanish (<code>es_es</code>) locale</strong>: added the 3 keys that were present in
<code>en_us</code> but missing from <code>es_es</code> &mdash; <code>item.workhand_tools.chunk_anchor</code>
and <code>block.workhand_tools.chunk_anchor</code> (&laquo;Ancla de chunk&raquo;) and
<code>item.workhand_tools.anchor_tome</code> (&laquo;Tomo de anclaje&raquo;). Values come from the
Mystical Realms Translation &amp; Fixes resource-pack QA pass and now ship with the mod itself, so
the overlay is no longer needed.</li>
</ul>

<h3>Notes</h3>
<blockquote>No gameplay change. Verified: <code>./gradlew clean build</code> is green. Only
<code>assets/workhand_tools/lang/es_es.json</code> changed (plus a tab re-indent of the file).</blockquote>
