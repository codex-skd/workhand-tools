<h2>v1.3.1 - Fix the placed Chunk Anchor being invisible (Minecraft 1.21.1)</h2>

<p>The <strong>Chunk Anchor block was invisible once placed</strong> in the world &mdash; only the
floating Anchor Tome showed up when one was inserted. The item in the inventory and in hand was
unaffected. Fixed.</p>

<h3>Fixed</h3>
<ul>
<li><code>ChunkAnchorBlock</code> extends <code>BaseEntityBlock</code>, whose
<code>getRenderShape()</code> defaults to <code>INVISIBLE</code> (it assumes a block-entity
renderer draws the whole block). The Chunk Anchor's body is an ordinary blockstate model and its
renderer only draws the hovering tome, so the pedestal never rendered. Added the
<code>getRenderShape() =&gt; RenderShape.MODEL</code> override that vanilla uses on the Spawner
and the Beehive. The pedestal model now shows whether or not a tome is inserted.</li>
</ul>
