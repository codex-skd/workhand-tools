<h2>v1.21.1 - Kennestroyer Tools, Full Recipe Book &amp; Fixes</h2>

<p>This is the first CurseForge update since v1.19.0, so it bundles everything from v1.20.0 and v1.21.0 together with this version's fixes.</p>

<h3>Feature</h3>
<ul>
<li><strong>Kennestroyer Ultimate Tools</strong>: added Kennestroyer Pickaxe and Kennestroyer Shovel — the ultimate tools with 5 mining/digging modes cycled via right-click:
<ul>
<li>Disabled: No area mining</li>
<li>Range 3 Flat: 3x3x1 (single layer)</li>
<li>Range 3 Cubic: 3x3x3</li>
<li>Range 5 Flat: 5x5x1 (single layer)</li>
<li>Range 5 Cubic: 5x5x5</li>
</ul>
</li>
<li><strong>Kennestroyer Pickaxe includes Vein Mining</strong>: breaks up to 128 connected ores of the same type automatically</li>
<li><strong>New tool material</strong>: KENNESTROYER (50,000 durability, 12.0 speed, +4 attack, 15 enchantability, repaired with Netherite Ingots)</li>
<li><strong>Crafting recipes</strong>: both tools crafted from Netherite Ingots, Diamond Blocks, Obsidian, and the top-tier Diamond Workhand tools</li>
<li><strong>Vellumli is now a required dependency</strong>: the mod will fail to load with a clear error message if Vellumli is not installed, so the in-game guide book is always available</li>
<li><strong>Complete recipe integration in the guide book</strong>: every tool and utility item has its crafting recipe displayed directly in the guide book using the native <code>vellumli:crafting</code> page type — no need for JEI to see recipes</li>
</ul>

<h3>Content</h3>
<ul>
<li>Guide book now covers every tool line with recipe pages, controls, stats and mechanic descriptions, fully translated in English (en_us) and Spanish (es_es):
<ul>
<li><strong>Pickaxes</strong>: 18 recipes (Stone/Iron/Diamond × all grades 1-4 + improved variants)</li>
<li><strong>Shovels</strong>: 12 recipes (Stone/Iron/Diamond × all grades 1-4)</li>
<li><strong>Axes</strong>: 2 recipes (Iron, Diamond)</li>
<li><strong>Hoes</strong>: 2 recipes (Iron, Diamond)</li>
<li><strong>Vein-Mining Pickaxes</strong>: 4 recipes (Improved Iron/Diamond, Advanced + Professional)</li>
<li><strong>Kennestroyer Pickaxe &amp; Shovel</strong>: full mode descriptions, controls, stats and crafting recipes</li>
<li><strong>Utility Items</strong>: 5 recipes (Tape Measure, Robust Stick, Chunk Anchor, Anchor Tome, Guide Book)</li>
</ul>
</li>
</ul>

<h3>Fix</h3>
<ul>
<li><strong>Compound tree felling was clearing adjacent trees</strong>: the axe's Compound felling mode could cross leaf gaps with no limit, letting it jump from one tree's canopy into a neighboring tree of the same wood type and fell it too. It's now capped to 2 consecutive leaf blocks — enough to cross a diagonal branch or offset canopy within the same tree, not enough to reach a separately planted tree nearby.</li>
<li><strong>Chunk Anchor border was visible from unlimited distance</strong>: in the default "Always" border mode, the corner-outline indicator ignored the client's actual render distance, so the tall corner lines stayed visible far beyond where anything else would render. Now capped to the player's effective render distance.</li>
<li><strong>Guide book had two corrupted entries</strong>: the Pickaxes and Shovels entries (English and Spanish) contained invalid JSON that could fail to load. Fixed and split into separate entries.</li>
<li><strong>Guide book recipe grade labels were swapped</strong>: Advanced/Expert grade numbers were exchanged on several pickaxe and shovel recipe pages, and Advanced/Professional were swapped on Vein-Mining Pickaxe pages. Corrected across both languages.</li>
</ul>

<h3>Change</h3>
<ul>
<li>Vellumli dependency changed from optional to required in <code>neoforge.mods.toml</code></li>
</ul>
