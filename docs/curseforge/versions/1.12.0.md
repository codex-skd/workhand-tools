<h1>Workhand Tools 1.12.0</h1>

<h2>&#127795; No More Trees Left Half-Chopped</h2>
<p>Workhand Axes now fell the entire tree in one hit &mdash; including the loose branch logs tucked inside the leaves that used to get left standing.</p>

<hr>

<h3>How it works</h3>
<p>The felling search used to only follow logs that were directly touching face-to-face, so any branch separated from the trunk by even a single leaf block stayed behind. It now searches all 26 neighboring blocks around each log (including diagonals) and can cross through leaf blocks to reach logs on the other side of a gap. Leaves are never broken directly &mdash; they still fall away on their own once their supporting logs are gone, same as before.</p>
<p>How many leaf blocks in a row it may cross before giving up on a branch is configurable in the mod config (<code>maxLeafDistanceFromLog</code>), unlimited by default.</p>

<hr>

<h3>Cross-mod compatibility</h3>
<p>Log detection no longer relies only on the vanilla log block tag. Any block whose id contains <code>_log</code> or <code>log_</code> is now also recognized as fellable, so trees from mods that don't tag their logs correctly get chopped whole too.</p>
