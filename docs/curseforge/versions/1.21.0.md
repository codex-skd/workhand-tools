<h2>v1.21.0 - Kennestroyer Ultimate Tools</h2>

<h3>Feature</h3>
<ul>
<li><strong>Kennestroyer Ultimate Tools</strong>: added Kennestroyer Pickaxe and Kennestroyer Shovel — the ultimate tools with 5 mining/digging modes cycled via right-click:
<ul>
<li>Disabled: No area mining</li>
<li>Range 3 Flat: 3x3x1 (single layer)</li>
<li>Range 3 Cubic: 3x3x3</li>
<li>Range 5 Flat: 5x5x1 (single layer)</li>
<li>Range 5 Cubic: 5x5x5</li>
</ul>
</li>
<li><strong>Kennestroyer Pickaxe includes Vein Mining</strong>: breaks up to 128 connected ores of the same type automatically</li>
<li><strong>New tool material</strong>: KENNESTROYER (50,000 durability, 12.0 speed, +4 attack, 15 enchantability, repaired with Netherite Ingots)</li>
<li><strong>Crafting recipes</strong>: both tools crafted from Netherite Ingots, Diamond Blocks, Obsidian, and the top-tier Diamond Workhand tools (Advanced/Professional Improved Pickaxe for pickaxe, Advanced/Professional Shovel for shovel)</li>
</ul>

<h3>Content</h3>
<ul>
<li><strong>Guide Book</strong>: added Kennestroyer Pickaxe and Shovel entries with full mode descriptions, controls, stats, and crafting recipes in both English and Spanish</li>
</ul>

<h3>Technical</h3>
<ul>
<li>Extended <code>AoEMode</code> enum with <code>FLAT_3</code>, <code>CUBIC_3</code>, <code>FLAT_5</code>, <code>CUBIC_5</code> modes</li>
<li>Extended <code>Grade</code> enum with <code>KENNESTROYER</code> grade supporting all 5 modes with dynamic lateral/height/depth calculation</li>
<li>Updated <code>AoEMiningHandler</code> and <code>AoEPatterns</code> to handle 5-mode cycling and pattern computation for Kennestroyer grade</li>
</ul>
