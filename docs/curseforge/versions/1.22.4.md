<h2>v1.22.4 - Reinforced Deepslate Pickaxe Behavior Fixed</h2>

<h3>Fix</h3>
<ul>
<li><strong>The pickaxe could still mine other blocks</strong>: mining speed against non-target blocks was the default 1.0 instead of 0, so it could technically break stone and other blocks (very slowly, with no drop). It's now truly unable to mine anything other than Reinforced Deepslate in Survival.</li>
<li><strong>It didn't drop Reinforced Deepslate when used on itself</strong>: the loot table only recognized the Diamond Workhand Professional Improved Pickaxe as a valid tool. The Reinforced Deepslate Pickaxe is now also accepted, so it can gather more of its own target block.</li>
</ul>
