<h2>v1.16.0 - Hoe Harvest Toggle, Area Preview &amp; Ground-Aware Tree Felling</h2>

<h3>Fix</h3>
<ul>
<li><strong>Beetroot harvest could be duplicated with Workhand Hoes</strong>: the crop age reset after harvesting hardcoded <code>CropBlock.AGE</code>, but <code>BeetrootBlock</code> uses its own age property (0-3 range) instead of <code>CropBlock</code>'s (0-7 range). Setting the wrong property threw at runtime after drops had already been granted, so the beetroot stayed mature and could be harvested again for free. The age property is now looked up dynamically from the block's own state definition, fixing wheat, carrots, potatoes, beetroot, nether wart, and cocoa alike.</li>
<li><strong>Right-click mode/effect toggles played no swing animation</strong>: toggling the hoe's harvest effect, the axe's tree felling, or the pickaxe/shovel's AoE mode cancelled the interaction without triggering the arm swing, so the tool looked static. All three toggles now swing the tool.</li>
<li><strong>Tree felling ignored where in the trunk the log was broken</strong>: any log break with felling enabled cascaded into the full tree, even at eye height mid-trunk. The cascade now only triggers when the broken log is resting on solid ground (the base of the trunk); breaking a log elsewhere in the trunk breaks only that single block.</li>
</ul>

<h3>Feature</h3>
<ul>
<li><strong>Area preview for Workhand Hoes</strong>: aiming a hoe at a mature crop, cocoa, or nether wart now outlines the exact square area that will be harvested, matching the preview pickaxes/axes/shovels already had.</li>
<li><strong>Harvest enabled toggle for Workhand Hoes</strong>: right-click with no target to enable/disable the hoe's harvest effect (enabled by default). When disabled, hoes behave like a vanilla hoe (e.g. tilling dirt).</li>
</ul>
