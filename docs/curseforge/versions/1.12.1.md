<h1>Workhand Tools 1.12.1</h1>

<h2>&#128295; Area Preview Fix</h2>
<p>Small follow-up to 1.11.0: the block outline shown while aiming with a pickaxe now correctly disappears down to a single block when its area mining is set to Disabled.</p>

<hr>

<h3>Fix</h3>
<p>The preview outline had not been updated when the Disabled mode was added and kept drawing the full flat/cubic area regardless of the tool's state. It now matches what actually gets mined.</p>
