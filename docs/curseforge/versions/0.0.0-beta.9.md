<h2>v0.0.0-beta.9 - Item model JSON templates</h2>

<p>Added complete item model JSON templates for all 80 workhand tools + robust_stick, enabling item icons to display correctly in the creative inventory and when held.</p>

<h3>Changes</h3>
<ul>
<li><strong>81 item model JSON files</strong> generated and committed to version control:
  <ul>
  <li>80 tools: 10 materials × 4 grades × 2 tool types (pickaxes and shovels)</li>
  <li>1 robust_stick item</li>
  </ul>
</li>
<li><strong>Texture mapping</strong>: Each model references vanilla placeholder textures (e.g., copper tools use iron pickaxe/shovel texture, deepslate uses stone, blackstone uses netherite for dark tone, obsidian uses diamond for gem appearance)</li>
<li><strong>All 81 item names</strong> already localized in en_us.json (translations completed in previous beta)</li>
<li>Removed duplicate generated models from src/generated/resources — single source of truth is now src/main/resources</li>
</ul>

<h3>Technical Details</h3>
<p>Model structure (example: iron_workhand_advanced_pickaxe.json):</p>
<pre><code>
{
  "parent": "minecraft:item/handheld",
  "textures": {
    "layer0": "minecraft:item/iron_pickaxe"
  }
}
</code></pre>

<h3>What's Working</h3>
<ul>
<li>All 80 tools and robust_stick now display icons in inventory, creative tab, and hotbar</li>
<li>Icons are visual placeholders using vanilla textures — not differentiated by grade yet (awaiting custom art assets)</li>
<li>Crafting recipes, enchancements, area-mining mechanics, and all gameplay features from previous betas remain unchanged and fully functional</li>
</ul>

<h3>Next Steps</h3>
<p>Custom texture art (80 tool textures + robust_stick) is being designed separately. Once completed, model files will be updated to reference the new textures instead of vanilla placeholders.</p>

<blockquote>This beta release completes Phase 7 (asset placeholder phase) of the implementation roadmap. All gameplay features are stable and ready for testing.</blockquote>
