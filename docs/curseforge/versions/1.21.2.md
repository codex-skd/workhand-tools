<h2>v1.21.2 - Critical Startup Crash Fix</h2>

<blockquote><strong>v1.21.1 crashed on startup for every player.</strong> Please update to this version immediately.</blockquote>

<h3>Fix</h3>
<ul>
<li><strong>Fixed a critical bootstrap crash</strong> introduced in v1.21.1: the mod failed to load with <code>IllegalArgumentException: ... onLoadComplete ... has @SubscribeEvent annotation, but takes an argument that is not valid for this bus</code>. The mod's Vellumli-required check was accidentally registered on the wrong internal event bus. This affected every player and every world, regardless of configuration or other installed mods.</li>
</ul>
