<h1>Workhand Tools 1.8.0</h1>

<h2>&#127912; Final Artwork, Complete</h2>
<p>The remaining 24 tool textures &mdash; Stone, Iron and Diamond, across all four grades, pickaxes and shovels &mdash; now display the designer's final art, replacing the last placeholder icons in the mod.</p>

<hr>

<h3>What changed</h3>
<ul>
<li>All <strong>24</strong> Stone/Iron/Diamond &times; Base/Advanced/Expert/Professional pickaxe and shovel textures updated with final custom artwork.</li>
<li>Combined with the improved pickaxes, workhand axes and Robust Stick finalized earlier, <strong>every item</strong> in Workhand Tools now uses final custom art &mdash; no vanilla or placeholder textures remain.</li>
<li>No gameplay, balance or code changes in this release.</li>
</ul>
