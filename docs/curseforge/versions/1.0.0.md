<h2>v1.0.0 - Workhand Tools Release</h2>

<h3>Overview</h3>
<p>First stable release of Workhand Tools for Minecraft 26.2 + NeoForge. Introduces pickaxes and shovels across three material tiers (Stone, Iron, Diamond) with four grades each (Base, Advanced, Expert, Professional). All 25 items now render correctly with custom textures and support full vanilla tooling mechanics including AoE mining, enchantments, and durability.</p>

<h3>Features</h3>
<ul>
<li><strong>24 Tool Variants</strong>: 12 pickaxes (3 materials × 4 grades) + 12 shovels (3 materials × 4 grades). Each grade adds visual reinforcement and AoE mining area expansion.</li>
<li><strong>Robust Stick</strong>: Unique crafting component with thickened handle and metal reinforcement band, used in tool recipes.</li>
<li><strong>Custom Textures</strong>: All 25 PNG assets with production-quality pixel art. Material differentiation (stone/gray, iron/silver, diamond/cyan) with grade progression clearly visible.</li>
<li><strong>Vanilla Tooling Mechanics</strong>: Durability, attack speed, and enchantability match vanilla Stone, Iron, and Diamond tools respectively. Full compatibility with Sharpness, Unbreaking, Mending, and all vanilla enchantments.</li>
<li><strong>Area Mining (AoE)</strong>: Grade 1 (base) = 3×3, Grade 2 = 3×3 + corners (5×5 sparse), Grade 3 = 5×5, Grade 4 (professional) = 5×5 + edges (7×7 sparse).</li>
<li><strong>Creative Tab</strong>: Dedicated tab with all tools and stick, organized by tool type and material progression.</li>
</ul>

<h3>Technical</h3>
<ul>
<li>Item registration via <code>DeferredItem</code> and <code>WorkhandPickaxeItem</code> custom class.</li>
<li>Item model definitions in <code>assets/workhand_tools/items/</code> (NeoForge 26.2 data component system).</li>
<li>Model JSON files in <code>models/item/</code> referencing custom textures and vanilla parent geometries.</li>
<li>Vanilla <code>ShovelItem</code> class for shovels; custom <code>WorkhandPickaxeItem</code> extends <code>Item</code> with proper pickaxe initialization.</li>
<li>AoE mining via <code>AoEMiningHandler</code> mixin event handler on harvest events.</li>
</ul>

<h3>Compatibility</h3>
<ul>
<li><strong>Minecraft</strong>: 26.2 (Java 25)</li>
<li><strong>Forge</strong>: NeoForge 26.2.0.37-beta</li>
<li><strong>Client/Server</strong>: Both</li>
</ul>

<h3>Known Limitations</h3>
<ul>
<li>Materials limited to Stone, Iron, and Diamond (80 tool variants from earlier betas removed for scope focus).</li>
<li>No custom sounds or particle effects; uses vanilla tool audio/visuals.</li>
<li>Enchantments are standard Minecraft enchantments; no custom enchantments added.</li>
</ul>
