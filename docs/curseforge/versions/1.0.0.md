<h2>v1.0.0 - First stable release (Minecraft 1.21.1)</h2>

<p>First stable release of Workhand Tools for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>
(Java 21). It consolidates the <code>0.0.0-beta.1</code> &rarr; <code>0.0.0-beta.7</code> line with
no further code changes. This build has been running in a full modded-server pack.</p>

<h3>What the 1.21.1 line brought</h3>
<ul>
<li><strong>API port of the 26.2 source</strong> (41 classes, no mixins). Full tool line unchanged:
12 pickaxes + 12 shovels (Stone/Iron/Diamond &times; 4 grades) with 3&times;3&rarr;5&times;5 area
mining and the Cubic/Flat toggle; 4 vein-mining pickaxes; 2 tree-felling axes; 2 crop-harvesting
hoes; Kennestroyer Pickaxe/Shovel; Reinforced Deepslate Pickaxe; Robust Stick; Tape Measure; Chunk
Anchor + Anchor Tome. Durability, speed and enchantability always match vanilla. Tool materials
ported to <code>SimpleTier</code>; the client render layer reverted to
<code>RenderLevelStageEvent</code> + <code>LevelRenderer.renderLineBox</code>.</li>
<li><strong>Client fixes</strong>: removed a stray <code>@EventBusSubscriber</code> that aborted
client mod loading (beta.2); added the missing <code>models/item/chunk_anchor.json</code> so the
Chunk Anchor no longer renders as the missing-texture placeholder (beta.3).</li>
<li><strong>Mode toggles</strong>: the Hoe / AoE-mining / tree-felling toggles moved off
right-click-event cancellation onto dedicated, rebindable keybindings (Options &rarr; Controls
&rarr; Workhand Tools), defaulted to the right mouse button; the optional network channel is now
<code>.optional()</code> so an older-jar server no longer disconnects clients (beta.4&ndash;5).</li>
<li><strong>Drop fix</strong>: AoE / vein / felling no longer duplicates the drops of multi-part
or special blocks (waystones, beds, tall flowers, the Chunk Anchor). <code>MiningHelper</code> now
mirrors the vanilla player-break sequence, so every block drops exactly once (beta.6).</li>
<li><strong>Spanish (<code>es_es</code>) locale</strong> completed.</li>
</ul>

<h3>Notes</h3>
<blockquote>No code change relative to <code>0.0.0-beta.7</code>. Verified:
<code>./gradlew clean build</code> is green; <code>./gradlew runServer</code> reaches
<code>Done</code> with 0 FATAL and 0 recipe/datapack parse errors. Requires Vellumli for the
in-game guide book. Shares this CurseForge project with the 26.2 line &mdash; pick the file that
matches your Minecraft version.</blockquote>
