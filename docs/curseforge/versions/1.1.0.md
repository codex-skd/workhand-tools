<h2>v1.1.0 - Sneak to fell one log at a time (Minecraft 1.21.1)</h2>

<p>Adds a per-swing override to the tree-felling axes: <strong>hold Shift while breaking a log
and the felling cascade is suppressed</strong> &mdash; only the log you are pointing at breaks,
the rest of the tree stays standing. Let go of Shift and felling works exactly as before,
whatever mode (Simple / Compound) the axe is set to.</p>

<h3>Added</h3>
<ul>
<li><strong>Sneak-cancels-felling</strong> on both Workhand Axes. This mirrors the behaviour the
pickaxes and shovels already have &mdash; sneaking has always disabled their area-mining pass &mdash;
so every Workhand tool now reacts to Shift the same way.</li>
<li>The axe tooltip gains the shared <em>&sect;7Hold Shift for normal mining</em> line so the
override is discoverable in-game.</li>
</ul>

<h3>Notes</h3>
<blockquote>The targeted log is still broken by vanilla in every case; Shift only skips the
connected-log cascade. No config, keybinding or recipe changes. Verified:
<code>./gradlew clean build</code> is green. Shares this CurseForge project with the 26.2 line
&mdash; pick the file that matches your Minecraft version. Requires Vellumli for the in-game
guide book.</blockquote>
