<h1>Workhand Tools 1.1.0</h1>

<h2>&#128295; What's New</h2>

<h3>&#127758; 10 Languages</h3>
<p>Workhand Tools now speaks your language! Full translations in English, Spanish, Portuguese, French, German, Russian, Chinese, Japanese, Italian, and Korean. Tool names, mode messages, and tooltip descriptions are all localized.</p>

<h3>&#128221; Descriptive Tooltips</h3>
<p>Every tool now shows exactly what it does:</p>
<ul>
<li>Mining area dimensions in gold (e.g. <strong>Area: 3x3x3</strong>)</li>
<li>Current mode for Grade 2 and 4 tools (Cubic / Flat)</li>
<li>Control hints: <em>Right-click to toggle mode</em> and <em>Hold Shift for normal mining</em></li>
</ul>

<h3>&#128064; Area Preview Highlight</h3>
<p>When holding a workhand tool and aiming at a block, the affected mining area is highlighted with yellow semi-transparent cubes. The preview updates in real time and disappears while sneaking — so you always know exactly what you're about to mine.</p>

<h3>&#128736; AoE Mining Fixed</h3>
<p>A critical bug where all workhand tools behaved as vanilla tools (no area mining) has been fixed. The internal grade/item lookup system now correctly initializes during mod setup, restoring the 3&times;3 to 5&times;5 area mining functionality for all grades.</p>

<h3>Controls</h3>
<ul>
<li><strong>Left-click</strong>: Break block + area (no sneaking)</li>
<li><strong>Shift + Left-click</strong>: Break single block (vanilla behavior)</li>
<li><strong>Right-click</strong> (Grades 2 & 4): Toggle Cubic / Flat mode</li>
</ul>

<h3>Materials</h3>
<p>All tools available in <strong>Stone</strong>, <strong>Iron</strong>, and <strong>Diamond</strong> — each with the same durability, mining speed, and enchantability as their vanilla counterparts.</p>
